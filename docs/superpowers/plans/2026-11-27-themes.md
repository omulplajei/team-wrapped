# Themes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a built page be themed: colours, font, a logo on the start and end screens, and background images that change per scene. The repo ships only a neutral default theme; a team's brand (colours and logo files) lives in a git-ignored private theme folder.

**Architecture:** A theme is a folder `themes/<name>/` with a `theme.yml` and asset files, found in the shared repo root, in `data/`, or in the chosen data folder (later wins). `build` resolves a theme (`--theme`, else the script's `theme:`, else `default`), injects its colours and font as CSS variable overrides, copies its assets next to the page, and adds the logo markup and backdrop list. The player CSS is rewritten to use those variables, with defaults equal to today's look.

**Tech Stack:** Python 3.11+ (pytest), vanilla CSS/JS player, `node --test`.

Builds on the earlier plans (all on `main`).

## Global Constraints

- No company branding, logos or brand colours are committed: the shared `themes/` folder (if any) holds only neutral themes; real brand themes live under `data/` (git-ignored) (spec sections 1 and 3).
- With no theme (the `default` theme) a built page must look and behave exactly as before: the CSS defaults equal today's colours, no theme assets are copied and no override style block is emitted.
- Theme values are validated before they reach CSS or HTML: colours must be `#hex` (3 to 8 digits) or `rgb()`/`rgba()` of numbers/percentages; the font must be a comma-separated list of up to 10 families, each a quoted name or a plain name, with balanced quotes; theme names must match `[A-Za-z0-9][A-Za-z0-9_-]*`; asset paths must be relative and stay inside the theme folder; backdrop opacity is a number in [0, 1].
- Pages must open from disk: theme assets are copied to `assets/theme/` next to the page and referenced by relative, URL-encoded paths.
- `build` writes nothing until everything (including the theme) is validated (spec section 13).
- Run tests with `python3 -m pytest -q` and `node --test tests-js/`; never commit anything under `data/` or `dist/`.
- Commit trailer, as a separate `-m` paragraph: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

- `theme.yml` keys: `name` (optional, must equal the folder name), `colors` (map of the keys above), `font`, `logo` (relative path), `backdrop` (`images`: list of relative paths, `opacity`: number). Unknown keys are errors.

```python
"""Themes: colours, font, logo and backdrop images for the player page (spec section 14)."""
from __future__ import annotations

import re
from dataclasses import dataclass, field
from pathlib import Path

import yaml

from .loader import LoadError

DEFAULT_COLORS = {
    "background": "#0f1115",
    "text": "#f2f3f5",
    "accent": "#5eead4",
    "warning": "#e6b450",
    "surface": "#3a3d44",
    "controls-bg": "rgba(0, 0, 0, 0.55)",
    "button-bg": "#f2f3f5",
    "button-text": "#0f1115",
    "focus": "#8ab4ff",
    "folder-top": "#f4c75f",
    "folder-bottom": "#e0a93b",
    "folder-tab": "#d99a2b",
    "folder-text": "#2a1f05",
}

_VARIABLES = {key: "--tw-" + {"background": "bg", "controls-bg": "controls-bg"}.get(key, key) for key in DEFAULT_COLORS}

_COLOR = re.compile(r"^(#[0-9a-fA-F]{3,8}|rgba?\(\s*[0-9.]+%?\s*(,\s*[0-9.]+%?\s*){2,3}\))$")
_FONT = re.compile(r"^[A-Za-z0-9 ,'\"._-]{1,200}$")
_KEYS = {"name", "colors", "font", "logo", "backdrop"}
_BACKDROP_KEYS = {"images", "opacity"}


@dataclass(frozen=True)
class Theme:
    name: str
    colors: dict
    font: str | None = None
    logo: Path | None = None
    backdrop_images: list = field(default_factory=list)
    backdrop_opacity: float = 0.35
    dir: Path | None = None


DEFAULT_THEME = Theme(name="default", colors=dict(DEFAULT_COLORS))


def _asset(folder: Path, value, what: str) -> Path:
    if not isinstance(value, str) or not value:
        raise LoadError(f"{folder}: {what} must be a file path")
    path = (folder / value).resolve()
    if Path(value).is_absolute() or not path.is_relative_to(folder.resolve()):
        raise LoadError(f"{folder}: {what} '{value}' must stay inside the theme folder")
    if not path.is_file():
        raise LoadError(f"{folder}: {what} '{value}' not found")
    return path


def load_theme(name: str, roots) -> Theme:
    found = None
    for root in roots:
        candidate = Path(root) / "themes" / name
        if (candidate / "theme.yml").is_file():
            found = candidate  # later roots override earlier ones
    if found is None:
        if name == "default":
            return DEFAULT_THEME
        searched = ", ".join(str(r) for r in roots)
        raise LoadError(f"theme '{name}' not found in: {searched}")

    data = yaml.safe_load((found / "theme.yml").read_text()) or {}
    if not isinstance(data, dict):
        raise LoadError(f"{found / 'theme.yml'}: must be a mapping")
    unknown = set(data) - _KEYS
    if unknown:
        raise LoadError(f"{found / 'theme.yml'}: unknown keys {sorted(unknown)}")
    if data.get("name", name) != name:
        raise LoadError(f"{found / 'theme.yml'}: name '{data.get('name')}' does not match folder '{name}'")

    colors = dict(DEFAULT_COLORS)
    given = data.get("colors") or {}
    if not isinstance(given, dict):
        raise LoadError(f"{found / 'theme.yml'}: colors must be a mapping")
    for key, value in given.items():
        if key not in DEFAULT_COLORS:
            raise LoadError(f"{found / 'theme.yml'}: unknown colour '{key}'")
        if not isinstance(value, str) or not _COLOR.match(value):
            raise LoadError(f"{found / 'theme.yml'}: colour '{key}' has an invalid value")
        colors[key] = value

    font = data.get("font")
    if font is not None and (not isinstance(font, str) or not _FONT.match(font)):
        raise LoadError(f"{found / 'theme.yml'}: font has an invalid value")

    logo = _asset(found, data["logo"], "logo") if "logo" in data else None

    backdrop = data.get("backdrop") or {}
    if not isinstance(backdrop, dict) or set(backdrop) - _BACKDROP_KEYS:
        raise LoadError(f"{found / 'theme.yml'}: backdrop has unknown keys or is not a mapping")
    images = backdrop.get("images") or []
    if not isinstance(images, list):
        raise LoadError(f"{found / 'theme.yml'}: backdrop images must be a list")
    opacity = backdrop.get("opacity", 0.35)
    if isinstance(opacity, bool) or not isinstance(opacity, (int, float)) or not 0 <= opacity <= 1:
        raise LoadError(f"{found / 'theme.yml'}: backdrop opacity must be a number between 0 and 1")

    return Theme(
        name=name,
        colors=colors,
        font=font,
        logo=logo,
        backdrop_images=[_asset(found, v, "backdrop image") for v in images],
        backdrop_opacity=float(opacity),
        dir=found,
    )


def css_overrides(theme: Theme) -> str:
    """CSS variable overrides for the page: only what differs from the defaults."""
    declarations = [
        f"{_VARIABLES[key]}: {value};"
        for key, value in theme.colors.items()
        if value != DEFAULT_COLORS[key]
    ]
    if theme.font:
        declarations.append(f"--tw-font: {theme.font};")
    return ":root { " + " ".join(declarations) + " }" if declarations else ""
```

```markdown
## 14. Themes

A theme controls the look of a built page: colours, a font, a logo on the start and end screens, and background images that change per scene. The repo ships only the neutral `default` theme (the built-in look); a team's brand lives in a private theme folder so that no company branding or trademarks are committed.

- **Folder.** `themes/<name>/theme.yml` plus asset files, found in the repo root, in `data/`, or in the chosen data folder; later locations override earlier ones. Brand themes go in `data/themes/<name>/` (git-ignored).
- **`theme.yml`.** `colors` (any of: `background`, `text`, `accent`, `warning`, `surface`, `controls-bg`, `button-bg`, `button-text`, `focus`, `folder-top`, `folder-bottom`, `folder-tab`, `folder-text`), `font`, `logo` (a relative path), `backdrop` (`images`: relative paths, cycled by scene index; `opacity`: 0 to 1). Unknown keys are errors.
- **Safety.** Colour values must be `#hex` or `rgb()`/`rgba()`, the font a plain font-family string, and asset paths relative and inside the theme folder; anything else is a load error. Nothing from a theme is inserted into the page unvalidated.
- **Choosing.** `build --theme NAME`, else the script's `theme:` key, else `default`.
- **Output.** Non-default colours and font become CSS variable overrides in the page; assets are copied to `assets/theme/`; the logo is shown above the title on the start screen and above Replay on the end screen; the backdrop images appear behind the scenes with a short cross-fade. With no theme the page is unchanged.
```
In `README.md`, add before the "## Tests" section:
```markdown
## Themes

`build` takes `--theme NAME` (or a `theme:` line in a script). A theme is a folder `themes/<name>/` with a `theme.yml` (colours, font, logo, backdrop images) and its asset files; put your own in `data/themes/<name>/`, which is git-ignored, so brand assets stay out of the repo. See section 14 of the spec for the format.
```
