# Odometer Counter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On scene one the counting number is drawn like an old gas-station / mechanical counter: a row of digit wheels whose digits roll upward, with the units wheel turning continuously and each higher wheel turning only as a carry from the one below.

**Architecture:** `presets.js` gets a shared scheduler (`scheduleCount`) used by both the text count-up and a new `odometer` widget, a pure `wheelPositions` function that says where each wheel sits for a value, and the `odometer` function that builds the wheels (DOM injected as an argument so the preset file stays testable in Node). `bignumber` gets a `counter` param (`"text"` default, or `"odometer"`). CSS draws the wheels with theme variables.

**Tech Stack:** classic-script JavaScript (presets, renderer) tested with `node --test`, GSAP timelines, CSS.

Builds on `2026-11-27-tail-beats.md` (on `main`).

## Global Constraints

- The default counter is unchanged: `countUp` produces exactly the same tweens as before (main tween to `to - beats` with the given ease, +1 beats of `min(0.05, pause)` s with ease `none`); `bignumber` without `counter` renders text exactly as before.
- Odometer count schedule is the same as the text count (same main count, same tail pauses), but each tail beat is a short roll: duration `min(0.3, pause)` s with ease `power2.inOut`.
- Wheel positions (in digits, 0 to 10): wheel 0 (units) is `v mod 10` (continuous); every other wheel k is `floor(v / 10^k) mod 10 + max(0, position(k-1) - 9)` (a carry cascade). A position of 10 shows the second "0" on the strip; the strip has 11 cells (0 to 9, then 0).
- Numbers keep the accent colour (digits inherit `color: var(--tw-accent)` from `.tw-hero-value`); no hard-coded hex colours in `player.css` outside the `:root` block (use `rgba(...)` and theme variables).
- The final state always shows the exact total; scrubbing backwards shows the right wheels (updates happen in `onUpdate` of tweens on one shared state object, as the text count-up does).
- `presets.js` must not touch `document` unless a `doc` is passed in (it is loaded in the browser and required in Node tests).
- Accessibility: the number element gets `role="img"` and an `aria-label` with the formatted final value when `setAttribute` exists; the wheels are `aria-hidden`.
- Renderers are classic scripts: exactly one `export default`, no `import`; textContent only.
- Run tests with `node --test tests-js/` and `python3 -m pytest -q`; never commit anything under `data/` or `dist/`; do not read or touch `data/` or `.claude/`.
- Commit trailer, as a separate `-m` paragraph: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

### Task 1: The odometer counter

**Interfaces:**
- Consumes: the current `countUp` (with ease and tail) in `web/presets/presets.js`; `format`; the helpers in `tests-js/helpers.js` (`makeEl` has `style: { setProperty }`, `append`, `children`, `className`, `textContent`).
- Produces:
  - `presets.wheelPositions(v, wheels) -> number[]` (index 0 = units wheel).
  - `presets.odometer(tl, el, to, at = 0, duration = 1.2, ease = "power1.out", tail = [], doc = document)`: fills `el` with wheels, schedules the same count as `countUp` (beats rolling over `min(0.3, pause)` s with ease `power2.inOut`), returns `tl`. DOM built (most significant wheel first): `span.tw-odo-wheel` > `span.tw-odo-strip` > 11 × `span.tw-odo-digit`; a `span.tw-odo-sep` (",") between groups of three; all wrapped in a `span.tw-odo` that is the only child of `el`. The strip's transform is `translateY(-<pos * 100 / 11>%)`. Wheels whose value and all higher digits are zero (not the units wheel) get `style.opacity = "0.3"`, others `"1"`.
  - `bignumber` param `counter`: `"odometer"` uses `presets.odometer` for the hero (passing `document`); any other value keeps `presets.countUp`.

- [ ] **Step 4: Refactor `countUp` onto a shared scheduler and add the odometer**

In `web/presets/presets.js` replace the current `countUp` function with the following three functions (the shared scheduler, `countUp`, and the wheel logic), and add `wheelPositions` and `odometer` to the exported `api` object:
```js
  // Schedules the main count and the tail beats on `tl`, calling show(v) whenever the value changes.
  // `beat` is {duration, ease} for the single-increment tail beats.
  function scheduleCount(tl, to, at, duration, ease, tail, show, beat) {
    const state = { v: 0 };
    const update = () => show(state.v);
    // Tail beats: the last few increments land one at a time, each after its own pause.
    const pauses = (Array.isArray(tail) ? tail : [])
      .filter((p) => typeof p === "number" && Number.isFinite(p) && p > 0)
      .slice(0, Math.max(0, Math.round(to)));
    const main = to - pauses.length;
    tl.to(state, { v: main, duration, ease, onUpdate: update }, at);
    let when = at + duration;
    pauses.forEach((pause, i) => {
      when += pause;
      tl.to(state, { v: main + i + 1, duration: Math.min(beat.duration, pause), ease: beat.ease, onUpdate: update }, when);
    });
    return tl;
  }

  function countUp(tl, el, to, at = 0, duration = 1.2, ease = "power1.out", tail = []) {
    el.textContent = format(0);
    return scheduleCount(tl, to, at, duration, ease, tail,
      (v) => { el.textContent = format(Math.round(v)); }, { duration: 0.05, ease: "none" });
  }

  // Where each wheel of a mechanical counter sits for the value v, in digits (0 to 10; index 0 = units).
  // The units wheel turns continuously; every other wheel only turns while the wheel below it passes 9 to 0.
  function wheelPositions(v, wheels) {
    const out = [];
    for (let k = 0; k < wheels; k++) {
      if (k === 0) {
        out.push(((v % 10) + 10) % 10);
      } else {
        const base = Math.floor(v / Math.pow(10, k)) % 10;
        out.push(base + Math.max(0, out[k - 1] - 9));
      }
    }
    return out;
  }

  // An odometer: a row of digit wheels that roll upward as the value counts up.
  function odometer(tl, el, to, at = 0, duration = 1.2, ease = "power1.out", tail = [],
    doc = typeof document !== "undefined" ? document : null) {
    const total = Math.max(0, Math.round(to));
    const count = String(total).length;
    const root = doc.createElement("span");
    root.className = "tw-odo";
    const wheels = [];                                   // index = wheel number, 0 = units
    for (let k = count - 1; k >= 0; k--) {
      const wheel = doc.createElement("span");
      wheel.className = "tw-odo-wheel";
      const strip = doc.createElement("span");
      strip.className = "tw-odo-strip";
      for (let d = 0; d <= 10; d++) {                    // 0 to 9, then 0 again so 9 can roll into 0
        const cell = doc.createElement("span");
        cell.className = "tw-odo-digit";
        cell.textContent = String(d % 10);
        strip.append(cell);
      }
      wheel.append(strip);
      root.append(wheel);
      wheels[k] = { wheel, strip };
      if (k > 0 && k % 3 === 0) {
        const sep = doc.createElement("span");
        sep.className = "tw-odo-sep";
        sep.textContent = ",";
        root.append(sep);
      }
    }
    el.textContent = "";
    el.append(root);
    if (typeof el.setAttribute === "function") {
      el.setAttribute("role", "img");
      el.setAttribute("aria-label", format(total));
      root.setAttribute("aria-hidden", "true");
    }
    const show = (v) => {
      const positions = wheelPositions(v, count);
      positions.forEach((pos, k) => {
        wheels[k].strip.style.transform = "translateY(" + (-pos * 100 / 11) + "%)";
        // leading zero wheels (not the units wheel) are dimmed, like unused digits on a pump counter
        wheels[k].wheel.style.opacity = k > 0 && Math.floor(v / Math.pow(10, k)) === 0 ? "0.3" : "1";
      });
    };
    show(0);
    return scheduleCount(tl, to, at, duration, ease, tail, show, { duration: 0.3, ease: "power2.inOut" });
  }
```
